# SrIruma Scoop Bucket

A Scoop bucket for tools published by [SrIruma](https://github.com/SrIruma).

## Usage

```powershell
scoop bucket add sriruma https://github.com/SrIruma/scoop-bucket
scoop install <app>
```

## Available apps

| App | Description |
|---|---|
| `repoctx` | Keep AI coding-agent context files (AGENTS.md, CLAUDE.md) truthful. |

More apps may be added over time.
